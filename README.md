# 卡王的导航

一个基于 HTML、CSS 和原生 JavaScript 的静态导航网站，整理 Minecraft、实用工具和游戏相关资源。

## 功能

- 按分类和分组浏览导航，并支持关键词搜索
- 浏览、筛选和搜索公告，查看公告详情及相关链接
- 支持浅色/深色模式、多种主题配色和响应式布局
- 支持友站链接、随机导航、卡片多链接展示
- 支持导入、导出本地设置
- 可选通过 GitHub API 在线编辑并保存导航数据

## 项目结构

```text
.
├── index.html             # 网站入口
├── data/
│   ├── script.js          # 交互逻辑与数据加载
│   ├── style.css          # 样式与响应式布局
│   ├── nav.json           # 导航分类、分组和链接
│   ├── notices.json       # 公告内容
│   ├── friends.json       # 友站链接
│   └── data2/             # 无云端同步的页面变体
└── images/                # 页面图片资源
```

项目无需安装依赖或执行构建。

## 本地预览

在项目根目录启动静态 HTTP 服务，例如：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。通过 HTTP 服务预览可避免浏览器对直接打开本地 HTML 文件时读取 JSON 的限制。也可以使用任意静态文件服务器或编辑器的本地预览扩展。

## 修改导航和公告

直接编辑 `data/nav.json`、`data/notices.json` 和 `data/friends.json`。这些文件必须保持有效 JSON；添加内容时可参照已有条目的字段结构。

- 导航数据按分类、分组和条目组织。
- 公告支持摘要、标签、置顶状态、详情内容和相关链接。
- 友站数据是链接列表；请替换或删除示例条目。

页面使用相对路径加载这些数据。部署时请保留目录结构，并确保静态主机能够提供 JSON 文件。

## GitHub 云端同步

设置面板中的可视化编辑可通过 GitHub API 将导航 JSON 保存到指定仓库。使用前需要配置仓库和有相应内容写入权限的 Personal Access Token。

Token 会保存在当前浏览器的本地设置中，浏览器会直接使用它访问 GitHub API。仅在可信设备上使用，并为 Token 配置最小必要权限；不要将 Token 提交到仓库或分享给他人。导出的设置不包含 GitHub Token。

## 部署

本项目可部署到 GitHub Pages 等静态托管服务。部署到不同域名或仓库路径时，请检查 `index.html` 中的 Open Graph URL 和图片地址是否仍然正确。
